# Security Policy

## Supported Versions

Security updates are provided for the latest version of this portfolio repository.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older   | No        |

## Reporting a Vulnerability

If you discover a security issue, please report it responsibly.

Please include:

- A clear description of the issue
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots or logs if available
- Impact assessment

Please do not disclose vulnerabilities publicly before they have been reviewed and addressed.

Contact options:

- Open a private security advisory on GitHub, if enabled
- Contact the repository owner directly through GitHub profile contact channels

## Response Process

Reported issues will be reviewed as quickly as possible. Valid security findings will be assessed, prioritized, and remediated depending on severity and impact.
