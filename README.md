## 🎯 Overview

A high-fidelity, motion-driven developer portfolio built to showcase Android engineering depth, GTFS/GTFS-Realtime transit-data expertise, and interactive data-validation dashboard work. Designed with kinetic typography, cinematic transitions, and a luxury-tech visual language — engineered for a performance-first, premium first impression.

- **Kinetic typography hero** — animated headline sequences tuned for smooth motion
- **Live GTFS/GTFS-Realtime case studies** — interactive breakdowns of transit-data architecture work
- **Android project showcase** — curated highlights of production-grade mobile engineering
- **Dark, luxury-tech aesthetic** — glassmorphism, gradient depth, and refined micro-interactions

### Prerequisites
- Node.js 18+
- npm 9+

```bash

```

